# Strategic Evolution

This file preserves the reasoning path so superseded ideas remain discoverable without competing with the canonical thesis.

## Stage 1 — Agent-native differentiation

Early exploration emphasized:

- user-owned personal agents
- community agents
- knowledge/provenance agents
- claim-level conversations
- transparent recommendation controls
- content passports
- project conversion
- evidence-based expertise
- agent interoperability

The useful insight from this stage was that a social network can combine a **social graph + knowledge graph + agent graph + governance graph**.

## Stage 2 — Governance-first correction

The strategy then identified a sequencing risk: a broad social/agent feature set creates too many simultaneous identity, spam, moderation, and authenticity failure surfaces.

The product narrowed to:

- identity/accountability semantics before autonomy;
- one social Space;
- provenance-aware content;
- bounded agents;
- explicit permissions and audit trails.

## Stage 3 — Governance-native refinement

The phrase `humans + agents as social actors` was judged too permissive and ambiguous for the intended trust model.

The canonical model became:

`humans in social communities + governed AI infrastructure + inspectable provenance + accountable delegated action`

This preserves future agent participation while making human accountability and bounded delegation the alpha default.

## Stage 4 — Governance UX

The remaining risk was governance that existed technically but was socially invisible.

The product therefore adds a Governance UX layer:

`normal social interaction → lightweight AI/trust label → context card → full audit/provenance record`

The alpha must prove that governance can be experienced as **trust, control, and clarity** without turning ordinary participation into compliance work.

## Frozen principle

> **Governance kernel first. Social Space immediately. Autonomous agency later, if earned by evidence.**

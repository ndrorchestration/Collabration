# ADR-0002: Contextual governance disclosure

- **Status:** Accepted
- **Date:** 2026-09-10

## Context

Always-visible technical governance metadata would overload ordinary social interaction, while hidden audit records would make the product's core differentiation invisible.

## Decision

Use three-level progressive disclosure:

1. trust/assistance chip;
2. concise context card;
3. full technical audit/provenance view.

Governance details appear contextually for AI-assisted, source-linked, disputed, recommended, or moderated content.

## Consequences

- Trust labels must be typed and actionable.
- Provenance must not be represented as truth verification.
- Casual human posting remains lightweight.
- Evaluation measures comprehension rather than raw action-log visits.

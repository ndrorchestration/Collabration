# ADR-0001: Governance-native social network

- **Status:** Accepted
- **Date:** 2026-09-10

## Context

Early Intellectro concepts considered autonomous agents as visible social participants and a broad feature set spanning community, professional networking, discovery, and AI assistance. That creates excessive identity, authenticity, moderation, and permission complexity before the core trust thesis is validated.

## Decision

Intellectro will be described and built first as:

> **A governed social network where humans build communities with accountable AI infrastructure.**

The alpha centers human communities, bounded delegated AI, inspectable provenance, and explicit accountability.

## Consequences

- Governance kernel work precedes public agent autonomy.
- One usable social Space must exist immediately so governance is tested in real interaction.
- Community and Claim Agents are the first two agent roles.
- Personal agents and autonomous posting are deferred.
- Future autonomy requires evidence and a new ADR.

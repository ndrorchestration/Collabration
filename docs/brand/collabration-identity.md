# Collabration Brand Identity

Date: 2026-09-16
Status: CANONICAL
Former canonical name: Intellectro

## Canonical identity

**Collabration** is the canonical product name for the governed human+AI social collaboration network previously named **Intellectro**.

The name intentionally combines three product ideas:

- **collaboration** — humans and AI work together in communities and shared projects;
- **calibration** — people, agents, permissions, confidence, trust, and expectations are continuously adjusted against evidence and feedback;
- **celebration** — useful contribution and shared accomplishment can be recognized without collapsing provenance into truth or reputation into authority.

Canonical brand language:

> **Metacollaborate. Metacalibrate. Metacelebrate.**

Supporting product description:

> **Collabration is a governed human+AI social network where communities can collaborate with accountable AI infrastructure while preserving provenance, authority boundaries, approvals, execution receipts, correction, and independent verification.**

## Naming contract

Use **Collabration** for all current product, UI, repository-facing documentation, package metadata, and new ecosystem records.

Use lowercase **collabration** for machine identifiers and slugs where a lowercase identifier is required.

Use npm scope **`@collabration/*`** for workspace packages.

Do not rewrite immutable historical evidence merely to erase the former name. When historical material needs disambiguation, use **“Intellectro (now Collabration)”** or **“Collabration (formerly Intellectro)”** according to chronology.

Existing external provider identifiers that cannot be renamed atomically remain historical/operational aliases until provider-level migration is completed. Their continued presence does not make Intellectro the canonical product identity.

## Epistemic boundary

This rename changes product identity only. It does not change, improve, or establish any implementation, runtime, authorization, security, evaluation, scientific, verification, deployment, or production-readiness state.

Existing PASS / VERIFIED / NOT VERIFIED distinctions remain bound to their original evidence and scope.

## Brand vocabulary

Preferred terms:

- Collabration
- Collabration community / Space
- human+AI social network
- accountable collaboration network
- human+AI teammate
- provenance
- authority boundary
- approval
- execution receipt
- correction / challenge / appeal
- independent verification

Avoid framing the system as a generic autonomous-agent network or implying that provenance, popularity, reputation, or AI confidence establishes truth.

## Historical alias

`Intellectro` is retained only as a historical alias for provenance, old URLs, old commits, external provider identifiers not yet migrated, and prior records whose chronology should not be rewritten.
